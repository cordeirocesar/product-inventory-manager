# Product Inventory Manager

A simple console-based inventory management application built with **Java**.

## Features

- **Add products** — add new products to the inventory.
- **Update products** — modify existing product information.
- **Remove products** — remove products by ID.
- **Search products** — find products by ID.
- **List products** — display all products in the inventory.
- **Data validation** — validate product information before adding or updating it.

## Technologies

- Java
- HashMap (Java Collections Framework)

## How to Run

1. Clone or download this repository.
2. Open the project in a Java IDE.
3. Run `Main.java`.

## About

This project was developed to practice **Java fundamentals** and **object-oriented programming (OOP)**.
